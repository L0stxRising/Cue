# Cue

Cue Turns what you just did on your screen into a written guide. No editing, no screenshotting manually, no writing steps by hand.

## How it Works
So Basically You start a Script, You DO Whatever You want to Record, For Each Step Click CTRL+CLICK or CTRL+ENTER => Whichever Is Suitable, Once You are done, Press CTRL+ESC , then Fill in the Info Regarding the Guide Like the Title, Some Notes etc.

## Why
I got tired of writing "click here, then click here, then type this" guides by hand every time someone asked me how to do something. Cue Automates this Boring process of the Making Guides.

## Controls

| Shortcut | What it does |
|---|---|
| `Ctrl + Click` | Take a screenshot |
| `Ctrl + Enter` | Take a screenshot (When Its Better like Idk filling a form maybe) |
| `Ctrl + Delete`| Delete the last screenshot you took (oops! wrong click) |
| `Ctrl + Esc`   | Stop recording, and pack up |

## Setup

You'll need an [OpenRouter](https://openrouter.ai) API key (This script uses the free Models so this can run for free).

1) Just Download the Suitable File from https://github.com/L0stxRising/Cue/releases/tag/Cue_V1

2) Run the Script anywhere (Most Preferably a Folder)


[IMP NOTE] : For MAC Os you need to Grant the Script Permissions to Record Mouse and Screen => Go to Settings -> privacy and Security -> Accessibility and Toggle switch ON for Terminal. Also Go to Settings -> privacy and Security -> Screen Recording and Do the Same.

[IMP NOTE] : Sometimes Due to High Demand, the Models Might Fail So Try again In a Moment.

[IMP NOTE] : Everything Is Done by the script You Don't Need to Run it With Admin/Root
